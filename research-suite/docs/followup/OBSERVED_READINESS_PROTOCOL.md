# Frozen observed-data readiness audit

October 19, 2026 UTC. This is a provenance/sampling/input-compatibility study, **not** a classifier performance test. No model predictions will be computed.

Source frame: official ZTF Bright Transient Survey Sample Explorer, documented CSV output, https://sites.astro.caltech.edu/ztf/bts/explorer.php?format=csv. Retain the exact query, retrieval timestamp and source-byte SHA-256 locally. The current default query's selection/quality cuts remain part of its frame; do not call it all transients. Cite the BTS source/paper; public catalog visibility is not asserted to supply a blanket redistribution license. Do not republish its full source table.

Select records whose classification begins with SN, with a nonempty ZTF ID and parseable coordinates, deduplicate ZTF ID, sort by SHA-256 of the exact ID and take the first20. This deliberately samples reported supernova negative controls, not kilonova positives or a representative alert population. These classification labels select the negative-control frame; no model or predicted score selects objects. Retain selected IDs, source classification and coordinates for traceability, with any exclusions counted. No classification is independently adjudicated by this project.

For the first selected object only, request public IRSA DR24 g/r photometry within1.5arcsec, excluding quality-mask32768, CSV response. Cache query/timestamp/hash, response schema, row count and candidate object-ID count. Multiple archive sources in the cone require explicit crossmatching; no automatic nearest-source choice or model evaluation. IRSA public-data terms and required acknowledgments are documented in ASTRONOMY_FEASIBILITY.md. No login or proprietary data requested.

Audit admission to the existing LSST-simulation models: require matching filter-system provenance, flux/uncertainty units and difference-image convention, alert detection/first-alert semantics, source identity and a justified physical mapping. A ZTF magnitude catalog with no detected_bool alert history and a different filter system fails direct admission. Do not manufacture these fields, treat all catalog detections as broker alerts, convert magnitudes and silently call the systems equivalent, or invent model scores. Report exact verified gaps and a source-based next step. Failure of this direct mapping is a blocker for this particular comparison, not a claim that all observed astronomy research is impossible.
