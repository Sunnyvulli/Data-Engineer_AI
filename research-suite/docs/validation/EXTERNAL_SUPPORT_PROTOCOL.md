# Frozen independent support-validation protocol

Prepared October 19, 2026 UTC before inspecting new target labels or computing new model outcomes. Earlier ALCE results are exposed. This study adds an independent human-annotated corpus and a coverage diagnostic; it does not erase benchmark reuse or establish deployment validity.

Repository MIT license credits Particle Media; its underlying QA passages come from MS MARCO, whose official terms permit free noncommercial research but do not grant ownership/redistribution rights in original web documents. This personal research does not redistribute passages, answers, questions or hallucination spans. Publish only source hashes, IDs, model risks and aggregates with attribution. Sources: https://github.com/ParticleMedia/RAGTruth and https://microsoft.github.io/msmarco/ . Human annotations concern supplied evidence, not universal factual truth.

Inputs fixed by SHA-256: source_info.jsonl `0dffc26ea9f3c1c3d7c7e8336b56ef1646e3cec876edffcca3c9c624d12d578b`; response.jsonl `e4c2e4ac24fff676d8984cc61c35d791612fadc58015335d97dd632375e18073`. No training on RAGTruth, including its train split. Select every published test response whose source task_type is QA. Do not exclude by generator, quality, label or score. Exclude complete source groups only when their whitespace-normalized lower-case question matches a question anywhere in ALCE; report exact-match exclusions. No claim of semantic deduplication or absence of pretrained contamination.

Response-level positive = one or more released human hallucination spans (including unsupported implicit_true spans); zero spans = negative under this annotation rule, not certified truth. Keep source_id clusters together for uncertainty because six model responses may share one question/context. Original quality flags are reporting strata only, never predictors. The external task has answer-level rather than ALCE sentence-level labels; disclose this construct/granularity shift and do not pool their metrics into a universal score.

## Frozen policies and new coverage diagnostic

Recreate the existing six-feature lexical logistic model separately for ASQA and ELI5 using the original seed42 training/validation question folds and parameters; require the original ALCE target AP/threshold to reproduce before external inference. Validation threshold targets >=90% source unsupported recall. No target labels set thresholds. Score the complete external response as text with one citation containing the exact source passages and an empty title. No question, prompt, labels, generator or quality fields enter model inputs.

Existing bounded NLI: immutable Apache-2.0 `cross-encoder/nli-deberta-v3-small` revision `fa2804872c3b4bd748f38c0185cc85775361e735`, using the existing hash-checked ONNX/tokenizer files and fixed 512-token evidence-first pair, 120-token claim cap, risk1 minus entailment probability. Reuse the previously source-selected NLI thresholds from nli-comparison.json. Record all truncation; answer-level labels can describe discarded text, a material limitation.

New coverage-window diagnostic, not claimed as a novel method: same frozen NLI weights. Tokenize without special tokens. Evidence windows have384 tokens and stride320; claim windows have120 tokens and stride100; include an end-aligned final window if necessary so every original token is represented. Missing evidence risk1. For each claim window take maximum entailment probability across all evidence windows; response risk is the maximum of1 minus those per-claim maxima. This is max/min aggregation, not a calibrated probability. Evidence windows can lose jointly supporting context and claim windows can split semantics. No cap on window count and no outcome-selected evidence retrieval. Decode token windows, encode pairs to512 with evidence-only truncation, and record any re-encoding truncation.

Calibrate coverage-policy thresholds only on each original ALCE source-validation fold, using the identical >=90% recall rule. Do not use source training labels for threshold fitting or inspect target outcomes to choose window sizes. The coverage policy is an explicitly new representation experiment; its source-validation inference is necessary new work, not a repeat of a completed model run. Persist inference risks before metric computation.

## Metrics, uncertainty and self-questioning

Report AP, ROC AUC, unsupported recall, supported false-positive rate, review fraction, missed unsupported count, source-validation thresholds and no-review/review-all controls. Use300 complete-source_id bootstrap resamples, seed20261019, with paired AP differences on identical target rows and review/recall intervals conditional on fitted models. Report quality/generator strata descriptively without selecting a winner; avoid significance hunting. Benchmark FPR/precision do not imply deployment prevalence or representativeness.

Questions to challenge before manuscript release: Are labels hidden from all inputs? Are source groups shared across responses? Does any target label select a threshold or configuration? Are answer-level results falsely presented as sentence-level validation? How much text was truncated? Does max-window aggregation bias longer inputs? Can a high overlap score conceal contradiction? Are identical-question or pretrained overlaps unmeasured? Do bootstrap intervals cover dataset/model-selection bias (they do not)? Retain negative results and code/data-access failures. No fabricated human adjudication or independent expert review.

ONNX CPU inference, four intra-op threads, batch4, no paid API/GPU. Save runtime/version/file hashes, inference counts, complete risk vectors and audit logs. Run integrity tests before target inference. Do not tune or retrain after outcomes. A paper must describe this as a bounded external benchmark and keep real deployment/human-learning claims out.
