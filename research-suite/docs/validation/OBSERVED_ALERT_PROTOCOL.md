# Frozen real-alert processing validation

Prepared 2026-10-19 before fetching this sample from ALeRCE. This is an observed-data ingestion/causality check, not kilonova classifier performance validation.

Use all 20 exact ZTF IDs previously selected by hash from BTS, recorded in results/followup/observed-readiness.json. No replacement for absent/error objects. Their provider classes are supernova negative controls; no positive kilonova population exists in this sample. Access the official unauthenticated ZTF API https://api.alerce.online/ztf/v1/objects/{oid}/detections once per object, with a 30 second timeout and no unbounded retry. The official service explicitly offers public object detections: https://science.alerce.online/services/ztf-database-api/ . Public ZTF survey releases/alerts and band definitions: https://www.ztf.caltech.edu/ztf-public-releases.html . Cite ALeRCE and ZTF. Public access is not a blanket redistribution license: keep raw packets local and publish object IDs, response hashes and derived aggregate counts only.

Accept only returned records with the exact requested object ID when an oid field is supplied, finite MJD, finite magpsf, finite positive sigmapsf, and fid 1 or 2 (ZTF g/r). Retain difference-sign values and report their distribution. Deduplicate exact candid identifiers; if one candid has conflicting complete payloads reject the object rather than select one. With no candid, deduplicate exact canonical JSON records and report fallback count. No outcomes or probabilities from provider models enter any computation.

Anchor at the earliest valid returned detection. This is earliest accessible API detection, not guaranteed true first alert or physical onset. Form inclusive 0..1/3/7-day prefixes. Report valid detections, g/r coverage, prefix counts, rejected/missing rows and HTTP failures for every selected object. Inject a copy of a valid row at anchor+1000 days with a new candid and modified magnitude; assert the earlier prefix summaries do not change. Test sorting and inclusive boundaries synthetically too.

Do not map ZTF filter IDs to LSST filter IDs, invent flux calibration, apply the LSST-trained model to incompatible magnitudes, or report AP/recall without positive examples. Store reproducible downloader and snapshot hashes. A completed test establishes only access and causal processing on this fixed, small, provider-selected negative-control frame. It leaves observed kilonova detection, contamination rates on a representative alert population and telescope utility unresolved.
