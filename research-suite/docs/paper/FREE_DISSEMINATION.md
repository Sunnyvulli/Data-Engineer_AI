# Free dissemination routes and submission boundaries

Primary policies checked October 19, 2026 UTC. No external paper submission has been made. A GitHub technical manuscript is not an accepted journal article.

| Route | Cost verified | What it provides | Remaining requirements |
| --- | --- | --- | --- |
| Existing public GitHub repository | Existing access; no paid services used | Versioned manuscript, original code, protocols and derived results | Not peer review, indexing or a DOI. Cite an immutable commit for reproducibility. |
| Zenodo | Official terms permit free uploads | Persistent research record and DOI after publication | Account, accurate creators, permission to distribute every file and chosen license. Raw third-party research text/data must not be bundled without rights. Repository posting is not journal acceptance. |
| arXiv | Official about page states no submission fees | Moderated scholarly preprint | Category suitability, account, possible endorsement, source files and moderation. Neither endorsement nor moderation is peer review. No acceptance promise. |
| Transactions on Machine Learning Research | Official policy states no author/reviewer/editor fees | Peer-reviewed open-access journal | Strong, well-supported contribution; anonymized submission and current template; editorial screening and independent review. Current draft is not claimed submission-ready for this venue. |

Suggested order: finish author review of the manuscript and claim audit; preserve one canonical version and code commit; choose one primary preprint record; link subsequent repository/preprint copies as versions of the same work. Do not present multiple website copies as multiple publications. A repository DOI and a later journal DOI are different objects and should be explicitly linked, not described as duplicate independent papers. Do not submit the same manuscript to multiple archival peer-reviewed venues concurrently. TMLR permits prior preprint overlap but forbids parallel archival submissions and reuse from prior archival papers.

Follow the destination disclosure requirements before submission. Human authors must verify all content and take responsibility; do not list an AI as an author. No invented affiliation, ORCID, coauthor, expert review or funding acknowledgement is allowed. Author confirmation of substantive authorship and final text remains necessary before an external submission.
